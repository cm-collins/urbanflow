# UrbanFlow - Development Roadmap

## Sprint 0 - Project Foundation

- Configure the development environment.
- Establish project architecture.
- Configure Git and GitHub.
- Complete project documentation.
- Establish engineering standards.
- Configure CMake and OpenGL dependencies.
- Implement the initial rendering window.
- Establish automated build validation.

## Sprint 1 - Viewing System and Rendering Foundation

- Implement the application lifecycle.
- Implement shader management.
- Implement viewing window boundaries.
- Implement window-to-viewport mapping.
- Implement orthographic projection.
- Implement perspective projection.
- Implement geometry clipping demonstrations.
- Implement camera movement and zoom.
- Implement framebuffer resizing.
- Test viewing transformations.

## Sprint 2 - Urban Environment

- Implement reusable 3D geometry.
- Create roads and intersections.
- Create buildings and sidewalks.
- Create traffic lights.
- Create trees and street infrastructure.
- Establish the city scene.

## Sprint 3 - Traffic Simulation

- Implement vehicle models.
- Implement vehicle movement.
- Implement traffic signal sequences.
- Implement vehicle stopping and acceleration.
- Implement basic collision prevention.
- Implement simulation timing.

## Sprint 4 - Visual Enhancements

- Implement lighting and shading.
- Implement materials and textures.
- Implement vehicle headlights.
- Implement street lighting.
- Implement optional day and night transitions.

## Sprint 5 - Interaction and Simulation Controls

- Implement interactive camera controls.
- Implement projection switching.
- Implement simulation pause and resume.
- Implement simulation speed adjustment.
- Implement viewing boundary visualization.
- Add optional emergency vehicle scenarios.

## Sprint 6 - Testing and Academic Delivery

- Validate functional requirements.
- Validate viewing window requirements.
- Perform performance testing.
- Resolve identified defects.
- Complete project documentation.
- Prepare executable distribution.
- Prepare academic presentation.
- Conduct final project demonstration.

## Scope Management

Mandatory academic requirements take priority over optional
visual enhancements and simulation features.

A functional application must be maintained throughout
the development lifecycle.
