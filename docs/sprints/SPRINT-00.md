deliver the first functional OpenGL application.

## Deliverables

- Configured development environment.
- Documented project architecture.
- Version-controlled source code.
- Reproducible CMake build configuration.
- Functional OpenGL application window.
- Initial rendered geometry.
- Basic framebuffer and viewport handling.
- Automated build validation.

## Definition of Done

- Required development tools are available.
- Project documentation is complete.
- Application builds without unresolved errors.
- OpenGL initializes successfully.
- Basic geometry is rendered.
- Window resizing updates the viewport.
- Source changes are committed and pushed.
- Applicable automated checks pass.

## Academic Requirement

The viewing window is a mandatory requirement.

Sprint 0 establishes the physical application window
and initial viewport handling.

Sprint 1 introduces explicit viewing boundaries,
coordinate mapping, projection and clipping demonstrations.
